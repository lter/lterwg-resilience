# Ancillary Resilience WG Scripts

These scripts are important/relevant to this group's activites but are not a part of the fundamental workflow that must be re-run iteratively. See below for script explanations.

## Script Explanations

- `expand-key.R` -- uses the `ltertools::expand_key` function to quickly/easily generate pre-formatted rows for inclusion in a data key (see `?ltertools::harmonize` for more context) as new 'batches' of raw data are slated for harmonization
